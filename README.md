## Projectes destacats

### 1. π Weather

Estació meteorològica amb Raspberry Pi Zero i sensor DHT11 per consultar dades meteorològiques des d'una interfície web.

[Repositori](https://github.com/fustcoma/pi-weather) · [Web del projecte](https://fustcoma.github.io/pi-weather/)

### 2. RebirthBot

Bot modular de Discord desenvolupat amb Python, amb ordres de moderació i altres funcionalitats per als servidors.

[Repositori](https://github.com/fustcoma/RebirthBot)

### 3. CP:GO

Mapa de Minecraft inspirat en Counter-Strike: Global Offensive, amb sistemes de joc implementats amb blocs de comandes i modificacions.

[Veure el projecte a Planet Minecraft](https://www.planetminecraft.com/project/counter-presence-global-offensive/)

### 4. Brainrot Legends

Projecte de tipus *clicker* amb botiga, millores, rebirths i aures.

[Veure els meus jocs a itch.io](https://fustcoma.itch.io/)
